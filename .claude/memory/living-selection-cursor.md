Main menu (`Code/UI/MainMenu.razor` + `.razor.scss`) selection/angled-UI system. All committed (through commit `c053d41`, 2026-06-08). VERIFIED in-engine, user happy. Ongoing polish — this is the handoff state.

**Living cursor (the gliding violet ring `.lh-cursor`):** one ring that glides between focusable items (mouse hover + keyboard both set `selectedIndex`). Position/size via inline `left/top/width/height/border-radius` (CSS transitions glide). **Transform is IMPERATIVE** — `ApplyCursorTransform()` sets `_cursorRef.Style.Transform = new PanelTransform()` each frame (no StateHasChanged → no re-render, no @keyframes-restart). PanelTransform API (confirmed): `AddPerspective(Length)`, `AddRotation(x,y,z deg)`, `AddSkew(x,y,z deg)`, `AddScale(Vector2)`, `AddTranslate(Length?,Length?,Length?)`. `using Sandbox` shadows bare `Box` → always `el.Box.Rect`.

**Ring wave (the "life"):** in `UpdateCursor`, `_waveSkewX/_waveSkewY/_waveRotZ` = SUM of two SLOW non-harmonic sines per axis (base + gentle detuned layer) from `Time.Now`. Slow only — fast/high-freq layers read as nervous "grasping" (user rejected). Folded into the transform as skew+rotateZ. Restart-proof (sine, not @keyframes). Tunables: base amps `4.5/1.6/0.8`, second-layer amps `1.4/0.7/0.35`, freqs `2.2,3.5 / 1.8,2.9 / 1.0,2.4`.

**In-panel control nudge:** controls inside a 3D-tilted panel (featured CTAs 7/8, card pills 9/10) are visually displaced by the panel's perspective; `UpdateCursor`'s nudge block applies the panel transform to the control center (uses `CursorPanel(i)` → the panel ref) so the ring lands right. Pills use the card ROW's pivot (`originY = pr.Top - 374` for idx 9/10). Per-item gap+radius in `CursorGeom(i)` (nav rows tightened to `(11,11,27)`; PLAY/discord 14; CTAs 11; pills 10).

**Filled-liquid nav selection (REVISED 2026-06-09, user loves the gap look):** the selected nav item (Roadmap/Options/Patch Notes = `.lh-item`) shows a SOLID NEUTRAL SLATE fill `rgba(58,56,66,0.97)` (NOT violet — the wave video bg is violet/magenta, violet-on-violet was mush; the bright `#9b6cff` ring is now the only saturated selection signal). Fill is a `.lh-item-fill` child at **inset 0, radius 16 (hugs the item)** with a LITERAL GAP of raw bg between fill and ring — the "View button look" the user pointed at; the animated bg shows through the gap. Fill keeps its OWN CLASHING liquid wave — `ApplyFillWave()` (amps `5.0/2.4/1.0`, freqs `1.6/2.3/1.1`), now called from Tick (NOT ApplyCursorTransform, which early-returns when cursor hidden). Nav rows shrink-wrap via `align-self: flex-start`.

**Persona pop + SelectedPop lockstep (2026-06-09):** sidebar now 13° (was 10°; CursorRot 0-3 = 13f/1300 in lockstep). `.selected` lunges `translateX(9px) scale(1.04)` (Discord 6px, utils 4px); base transforms carry identity translateX/scale so the lists interpolate per-function. `SelectedPop(i)` in MainMenu.razor mirrors the CSS pop into UpdateCursor's rect target (visL/visT/visW/visH + popX on the rotateY pivot) so ring+gap+fill stay concentric through the pop — the pop rides the cursor's 0.27s glide for free.

**PLAY gold is STATIC — liquid was VETOED (2026-06-09, motion sickness):** a liquid skew on a surface as large as PLAY at the player's focus point made the user motion-sick — tried selected-only with eased amplitude, still vetoed. **Do not re-add motion to large surfaces near focus.** Liquid lives ONLY on the small nav fills (mostly hidden behind text). PLAY feedback = Persona pop + gradient brighten + ring. The `.lh-play-liquid` child layer remains in markup (the sheen clips to it) but is never transformed. ALL gold glows removed (PLAY breathe halo, Play Now CTA, View pill) — style rule: **on the wave bg, glows are out; crisp edges + motion draw the eye.** User also flagged "little strokes everywhere feel AI-generated" → direction: purge hairline translucent borders in favor of solid slabs/color blocks (pending pass).

**Wave bg (2026-06-09):** `Assets/ui/main menu/loopbackground_wave.mp4` — native h264 1080p60, 8s loop, played by VideoBackground at FULL opacity (the old static PNG layer + light beam are deleted). **s&box VideoPlayer = h264 mp4 ONLY — VP8/VP9 webm fails with "No supported streams found."** Stale-path guard in MainMenu.OnStart respawns the component if VideoPath changed.

**Angled UI (RESOLVED — see [[angled-ui-featured-card]] for the full why):** s&box has NO `perspective` property + NO `preserve-3d` (only the `perspective()` FUNCTION) → can't share a 3D camera across separate elements. The fix = ONE transform per group. Bottom card ROW `.lh-cards` holds ONE `perspective(2000px) rotateY(10deg); transform-origin: left -374px` — the two slots are COPLANAR children (explicit `flex: 0 0 calc(50% - 13px)` widths, since flex-grow is poisoned under a transform). The `-374px` origin Y points the row's vanishing point at the featured card's so the gap between them is uniform. Featured `.lh-featured` + sidebar buttons each have their own `perspective()+rotateY(10deg)`. Layout: `.lh-main { left: 452px; padding: 42px 48px }`.
