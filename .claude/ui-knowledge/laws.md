# UI Laws — Beastborne (always read for UI work)

The durable rules for s&box Razor UI work in this repo, distilled from the full learnings history (Apr–Jul 2026). The `CLAUDE.md` quirks table is authoritative and already loaded, so nothing it says is repeated here. `guiding-star.md` is the style spec, read alongside this file.
The full dated history is `learnings-archive.md`. Grep it by panel, class, symptom, or the src heading cited below, and never read the whole file.

## Maintenance rules
- **Cap: ≤120 bullets / 40 KB.** At the cap, a new law must merge with or replace an existing one.
- **Keep only durable, generalizable rules here.** Session narration, per-panel changelogs and pixel specifics go in a dated section appended to the end of `learnings-archive.md`.
- **Newer evidence wins.** When a law is overturned, edit it in place. Don't append a bullet that contradicts it.
- **Check anything tagged ⚠️ unverified in-editor before relying on it.** Drop the tag once it's verified.
- **Propose rules that apply to nearly every task for promotion to CLAUDE.md**, which the user owns.

## Engine: CSS & layout
- **Size full-fill or full-viewport absolute layers with `top: 0; left: 0; width: 100%; height: 100%`.** On a childless element, the four `top/left/right/bottom: 0` offsets resolve to ZERO size, so the backdrop or shield never renders. _(src: "Phone launcher v2 — app icons + accent swipe", 2026-07-01)_
- **Declare `display: flex` together with `flex-direction` on every non-leaf container, including fresh modals.** `flex-direction: column` alone doesn't make a column, and the children row up or collapse. _(src: "SkillTreePanel batch polish", 2026-04-18)_
- **Treat z-index as ONE flat ladder: grep the panel's scss for `z-index` and fit into it.** s&box has no stacking contexts, and unset z falls back to DOM order. Also grep for blanket `> *` position/z rules, which beat a new overlay unless it is out-specified (`.panel-root > .overlay`). _(src: "Roster sweep — living ring on a SCROLL grid + panel z-ladder", 2026-07-02; "Feedback responses", 2026-06-03)_
- **Stylesheet selectors are GLOBAL, and tie order across sheets is unspecified.** Use a panel-prefixed class namespace, and override shared components element-scoped (`MonsterCard .monster-card`). Leave colliding legacy bare-name rules soup-frozen, because other panels may rely on them. Avoid attribute selectors (`[class*="x-"]`) ⚠️ unverified. _(src: "Sweep — rewards/meta popup family", 2026-07-03)_
- **Define `@keyframes` in every `.razor.scss` that uses them, and write each block multi-line (`0% { ... }`).** Don't use `@import` partials, Sass `@for`/`@each`/`@mixin`, or `perspective()` chains inside keyframes: each is skipped silently. Grep the log for `malformed` after adding keyframes. _(src: "Sweep — system-popup dock tier", 2026-07-02)_
- **Don't use `var()`, `color-mix()` or `#rrggbbaa`. Build data-driven colors with one C# `Hex2Rgba(hex, alpha)` helper (safe fallback), inject them inline, and keep the SCSS rule generic. Format EVERY inline float with `CultureInfo.InvariantCulture`.** A comma-decimal locale makes s&box reject the style. For radial bursts, write one baked `@keyframes` per mote. _(src: "Hex → rgba helper for inline-style dynamic colors", 2026-04-17)_
- **Always emit an inline `style=` property and swap only its VALUE, and keep state colors that stylesheet `:hover`/`.selected` must override out of inline styles.** A property dropped from a later render stays applied (ghost tints), and inline beats every selector. Put per-item tints on low-alpha `background-color`. _(src: "PawPad v5 — icon set, System Dock, and the projection laws", 2026-07-02)_
- **Under ANY transformed ancestor, compute bar and fill widths as px in C# (`GetStatBarPx`) and give buttons explicit px widths, not `%` or `flex: 1`.** This is CLAUDE.md's translate poison, triggered by any transform. Transform entrances there use fill `none`, while opacity-only ones may use `both`. _(src: "Sweep — QuestPanel notice board", 2026-07-02)_
- **Inside scroll columns, keep each row/section rule SELF-CONTAINED: one class holds explicit height, `flex: 0 0 auto`, `display: flex` and explicit-width cells, with no padding-less wrappers.** Otherwise the LAYOUT height collapses: it paints, but siblings overlap it. Fix it by dissolving the nesting, not by pinning heights. _(src: "Nested flex wrapper inside a scroll column collapses", 2026-07-02)_
- **Give scroll-column children opacity-only entrances and no hover scale. Put slide motion on a transform-safe sibling, ambient decor in a non-scrolling band, and sub-dialogs as root-level sibling modals.** Even a `translateX(0)` child escapes the clip, which supersedes the old "small downward entrance is OK". To lift a button in a scroll card, animate its icon. _(src: "Scene Identity v3.1 deltas", 2026-06-11)_
- **Keep overhanging decorations INSIDE any `overflow: hidden` ancestor, with positive insets, and park hidden ones in-bounds at `opacity: 0`. To let particles escape a clipped modal, use a `pointer-events: none` SIBLING layer in `<root>`.** Clipping of absolute children is unreliable both ways (see Unresolved), and in-bounds is safe regardless. _(src: "Concept C — Launcher Hub", 2026-04-28; "DailyPanel Phase 1", 2026-04-08)_
- **[scroll grid] Give a card that must clip decoration `overflow: visible`, let the decorative child clip with a matching radius, and add a `min-height`.** A full-width hero card with `overflow: hidden` in a flex-wrap scroll grid painted at zero height. _(src: "CRITICAL DIAGNOSIS: a full-width", 2026-04-17)_
- **Center without percentage vertical margins or full-width text.** `margin-top: N%` resolves against parent WIDTH, so use flex centering or `top: 50%` + `translateY(-50%)`. A `text-align: center` span at `width: 100%` sticks left, so shrink-wrap leaf text under `align-items: center` instead. _(src: "MainMenu editorial-cinematic redesign", 2026-04-19; "App-color identity pass", 2026-07-12)_
- **Make a chip beside a flex column an absolute overlay on a `position: relative` ancestor, not a flex-row sibling.** As a sibling it hit the 3+-sibling failure ("DEV" stacked one letter per line). _(src: "Concept C — Launcher Hub", 2026-04-25)_
- **In an `overflow: hidden` flex row that ends in a `margin-left: auto` pill, give the text sibling `flex: 1 1 auto; min-width: 0`.** Otherwise a long title pushes the pill past the clip. _(src: "Style observations", 2026-06-08)_
- **To recolor a gradient-based element, also clear the gradient (`background-image: none`).** A gradient paints ON TOP of `background-color`, so a color-only override looks ignored. _(src: "Input / keyboard", 2026-05-18)_
- **Never fractionally scale pixel-art sprites.** Hover lift is `translateY(-2..3px)`, and to make things "feel BIG" raise native px values (fonts, spacing, radii) ~20–33%. `scale(1.06)` blurs a 128px sprite even when pixelated, and only integer scales are safe. Older panels still scale, so don't copy them. _(src: "Pixel-art sprite hover juice", 2026-04-14)_
- **Put rotation on an inner shell, so the unrotated outer wrapper hosts tooltips, badges and hover scale. To counter-rotate an `<iconify>`, transform a wrapping `<div>`. Rotate or skew only `pointer-events: none` elements** ⚠️ unverified reason. Absolutes inside a rotated parent use its rotated axes. _(src: "MainMenu editorial-cinematic redesign", 2026-04-23)_
- **[3D / PawPad] Only the per-element `perspective()` function works: standalone `perspective` and `preserve-3d` don't, and there's no shared camera. Under a leaned ancestor, align with flex-start stacking plus explicit px only.** Centering reads auto-width children as zero-width. Absolutes at the transform holder paint unleaned, so put rings and borders on the holder itself. _(src: "PawPad v4.1 — live verification verdicts + the FINAL alignment law", 2026-07-01)_
- **Bake what CSS can't draw (wide soft ellipses, hatch stripes, layered animated wallpapers) to lossless WebP at NATIVE size, under a VERSIONED filename.** PNG dulls translucency, lossy WebP drops alpha, and a same-path overwrite never refreshes the running game. Tiled drift layers need integer geometry. _(src: "PawPad v7.2–7.4 — mouse router, render-space laws, texture laws", 2026-07-02)_
- **[row lists] Accent only SOME rows with `box-shadow: -3px 0 0 <color>`, not `border-left`.** A border changes the box, so accented rows shift against their neighbours. _(src: "Prefer `box-shadow: -Npx 0 0 color`", 2026-04-16)_

## Engine: Razor rendering & performance
- **Choose animation by mount lifecycle.** A persistent element that stays painted gets a transition on a class toggle, and an entrance or replay gets `@keyframes` on a FRESH mount (`@if` + `@key`). A transition needs a painted prior frame: mount CLOSED, wait a frame, then add `.open`. An ancestor class toggle never replays a child's keyframes. _(src: "Concept C — Launcher Hub", 2026-06-03; "Menu features pass", 2026-06-09)_
- **Check how GameHUD hosts a panel before picking an entrance.** `@switch (currentTab)` children remount every open, so keyframes and `OnAfterTreeRender(firstTime)` replay free. `IsVisible` roots persist and need transitions or a version key. For example, BeastiaryPanel remounts, while ContractNegotiation and ExpeditionPanel persist. _(src: "Style observations", 2026-06-03)_
- **To replay a one-shot on a persistent element, mount a SEPARATE overlay keyed by a version counter (`@if (justSelectedId == id) { <div class="select-pulse pulse-@ver"/> }`), bump it per fire, and put both fields in `BuildHash()`.** A remount `@key` must be unique and computed in a C# helper (no inline `$"..."`, see the generator traps). In a `foreach`, the diff reuses slots by index. A `swap-@ver` parent class remounts its children for view swaps. _(src: "Canonical one-shot select-pulse pattern", 2026-04-17)_
- **Treat any class-string change as a potential remount that replays mount keyframes.** Keep mount animations off volatile-class elements (`kb-focused`, armed), and scope pops to rare state classes (`.pb-new`, `.slotted`). Don't key sections that hold width-transition bars. Toasts get entrance keyframes and exit via `.leaving` plus a transition. _(src: "Reactivity pass — view-swap / beast-switch choreography", 2026-07-05)_
- **Never let visibility depend on a keyframe completing (`opacity: 0` base + `forwards`).** If the animation or selector fails, the panel renders empty. Hidden rest states are allowed only behind a class-gated transition, using a selector that panel already proves. _(src: "Feedback responses", 2026-04-09)_
- **An animation owns every property it animates.** It overrides the static base transform (skew, rotate, centering) and `:hover`/`.selected` values. Bake the base into EVERY step, animate a different property, or move the loop to a child. Make a one-shot's resting CSS equal its end state, or use `animation-fill-mode: both`. _(src: "s&box CSS quirks", 2026-06-05; "Concept C — Launcher Hub", 2026-06-03)_
- **Write every state of a transitioning transform with the SAME function list (`translateX(0) rotateY(13deg) scale(1)`), and re-compose offsets (`translateY(-50%) scale(1.1)`) in each state.** Mismatched lists snap, and a bare `scale()` drops the centering. _(src: "Style observations", 2026-06-09)_
- **On a panel with `SpriteAnimator.GlobalFrame` (or any per-frame input) in `BuildHash()`, use ZERO `animation-delay`, overlays included, and no multi-stage conditional-class reveals.** Grep `animation-delay|animation:.*[0-9]s +[0-9.]+s`. About 20 Beastbook staggers died this way, and re-diffs restarted `entered` transitions. _(src: "Specimen Hall — Beastbook identity build", 2026-07-12)_
- **For inline `transition-delay` staggers, use transition LONGHANDS (never the shorthand), put delays only on the open state, reset them on `:hover`, and cap them (`min(index,12)*0.035s`).** The shorthand zeroes the delay. Re-assert state opacities (claimed rows at 0.65) with higher specificity. _(src: "s&box CSS quirks", 2026-06-03)_
- **For a C#-driven staged reveal, use one `revealStage` int in `BuildHash()` stepped by `await GameTask.DelaySeconds(≥0.1)`, with `@(revealStage >= N ? "entered" : "")` and a plain transition.** The render cadence misses steps under ~100ms. _(src: "Feedback responses", 2026-04-09)_
- **CSS transitions also apply to imperative `Style.*` writes.** A per-frame `Style.Transform` under `transition: transform` turns to mush, so toggle a transition-suppressing class. Imperative left/top/width writes glide for free. _(src: "Menu features pass — detonation / deal-in", 2026-06-09)_
- **Put each text fragment in its own `<span>` spaced by flex `gap`, and never mix bare text, elements and several `@` interpolations in one run. Where text and a value share a span, use one `@($"LV {GetLevel()}")` or a hoisted local.** s&box drops whitespace next to elements, squashes `LV @tier · @title`, and printed `Lv@(loreIdx) to unlock` literally. _(src: "Beastbook dossier — demolition complete", 2026-07-13)_
- **Avoid the razor-generator traps: `$"..."` in attribute expressions, `@if`/`@foreach` text in HTML comments, nested double-quoted literals in attribute ternaries, and `style="url(@M("a"))"`. Precompute the value in C#.** Each one gives `} expected` or a dangling `if`. Keep the `</div>`-before-`}` shape when moving markup. _(src: "PawPad v6/v7 — animated icons, Graphite handoff, razor generator laws", 2026-07-02)_
- **Keep Razor index counters as CLASS FIELDS, reset in `@{ _i = 0; }` at the top of `<root>` and bumped inline (`int idx = _i++;`), or use `@for`.** An `@{}` local is out of scope in a sibling `@foreach`, which failed silently and left the panel unrendered. _(src: "Project conventions", 2026-05-17)_
- **When a branch swaps DIFFERENT tag types (`<img>` vs `<iconify>`), keep both mounted and toggle a parent class (`has-x`/`no-x` → `display: flex|none`).** Only an attribute changes, so there's no ghost child. _(src: "Stable-DOM alternative to the shop's tuple-helper", 2026-04-17)_
- **`Box.Rect` is PRE-transform layout space in screen px. Multiply by `ScaleFromScreen`, mirror any CSS transform (pop, lean) in C#, and defer reads one tick after a state change.** There's no scroll-into-view: find the target via recursive `HasClass` and set `ScrollOffset.y`. _(src: "PawPad v5 — icon set, System Dock, and the projection laws", 2026-07-02)_
- **Build the living ring from `L/T = rect − inset; W/H = rect + 2·inset`.** Make it a LATER sibling of the bg-carrying element. Write it from Tick only on change and let transitions glide it. Self-hide it when the target leaves the scroll viewport. After view swaps, poll until the target rect is real for 2 frames. Absolute rings paint behind their own parent's fill. _(src: "Sweep — Online hub presence cards", 2026-07-02; "App-color identity pass", 2026-07-12)_
- **Never rely on `@ref` alone.** Loop refs don't exist, and refs in `@if` go stale while reporting a frozen `Box.Rect`. Resolve by fresh `HasClass`/`FindByClass` traversal from a stable container. _(src: "Scene Identity v3 implementation", 2026-06-10)_
- **`OnAfterTreeRender` fires only on `@inherits Panel`, never on a `PanelComponent`.** Use Tick with frame guards, and confirm a new hook logs before trusting it. _(src: "Scene swap hitch root-cause", 2026-06-10)_
- **Hotload safety: keep behavior branches in code, not static data flags. Never rename fields on static-registry types, sign-check `Time.Now` deltas (`dt >= 0f && dt < w`), have hosts re-register every frame, and have singletons re-assert `Instance = this` in Tick.** Statics migrate by field NAME, and `Time.Now` resets per session, which wedged every hotkey once. _(src: "PawPad v3.1 — right-anchor, sweep root cause", 2026-07-01)_
- **[PawPad / 3D] Never dirty a `perspective()`/3D subtree per frame, whether with Style writes, StateHasChanged or animated classes. Keep cursor updates event-driven.** One per-frame write dropped the leaned phone from 85fps to 7fps. Flat panels are fine. _(src: "PawPad v4 — device bezel, fps crater", 2026-07-01)_
- **[scene swap] Park large always-mounted subtrees offscreen (`left: -10000px` ↔ `0`, with `Left > -1000` rect checks) instead of flipping `display`, and keep the source screen mounted through a transition (`.hidden` gated on `IsVisible || transitionPhase > 0`).** A display flip costs a 90–230ms first layout. _(src: "Scene swap hitch root-cause + LighthouseScene split", 2026-06-10)_
- **When a modal opens from two screens (MainMenu and GameHUD), mount one instance per screen in a `List<T>`. `Show()` picks the one with no `.hidden` ancestor, and `Hide()` closes all.** A single `Instance` opens invisibly. _(src: "MainMenu editorial-cinematic redesign", 2026-04-20)_
- **[draggable popup] Keep the root static, put `transform: translate` on a rule-less inner wrapper, and mount the drag shield only while dragging, as a SIBLING (`top/left: -4000px; width/height: 8000px`).** `MousePosition` is panel-local, so translating the listener shakes. _(src: "Concept C — Launcher Hub", 2026-04-24)_
- **Animate bar fills by writing an integer px `width` under `transition: width`. Never use a reset-to-0 + `Task.Delay` hack.** Overshoot easing is only for one-shots, not live bars. _(src: "Stat-bar transitions — delete the Task.Delay", 2026-04-14)_
- **Template repeated rows with a `RenderFragment` helper (`private RenderFragment Row(string icon, …) => __builder => { <div>…</div> };`).** Closure capture and attribute interpolation work. _(src: "SkillTreePanel batch polish", 2026-04-18)_
- **[battle] Sync readouts to `BattleSceneController.OnTurnVisualsStarted`, not `BattleManager.OnTurnExecuted`.** The simulation runs 1–2 turns ahead of the visuals. _(src: "Project conventions", 2026-04-24)_

## Input & focus
- **Follow the input grammar.** WASD moves, and seams walk into filter bars and tabs. Space confirms, with E as a silent alternate (never `attack1`). Q backs out of everything: set `GameHUD.PanelHandledBackKey`, and bind no new `Escape` handlers. R is the page's shown cycle key. Z/X (`CyclePrev`/`CycleNext`) is the silent cycle pair. M opens the phone. `PrevWeapon/NextWeapon` don't exist. _(src: "Beastbook design brief authored for the Claude Design loop", 2026-07-12)_
- **Register every blocking popup in `UIModalState.TopModal` (ConfirmDialog highest), and gate `Tick()` input on `UIModalState.IsTopModal(...)` after `if (!IsVisible) return;`, using `Input.Pressed`, never `Down`.** Presses are global, so without the gate every layer consumes them. Dual-mounted panels expose a static `AnyVisible`. _(src: "Project conventions", 2026-05-17)_
- **Any key that both opens and closes or routes through a modal needs the `NavManager.RoutedThisFrame` latch, with `NavManager.MarkRouted()` on every non-NavManager launch (`X.Show()`).** The press stays edge-true for the next handler in the same frame: the phone closed itself instantly. _(src: "Phone launcher prototype + NavManager wiring", 2026-07-01)_
- **One cursor: mouse hover IS selection.** Hover writes the index the keyboard walks, and the violet ring plus `.kb-focused` serve both devices, with no separate `:hover` styling on cursor hosts. Show focus by recoloring a reserved transparent border, never by adding width, transform or shadow. Commit heavy selections after a ~110ms dwell. _(src: "One-cursor + feel pass + inline fusion result", 2026-07-06)_
- **Implement all three legs of the device-mode contract: one `lastInputDevice` flag drives root `.kbd-mode`/`.mouse-mode`, a guarded root `onmousemove` flips to mouse, and EVERY owned `:hover` is gated under `.mouse-mode` while hover handlers ignore `onmouseover` in keyboard mode.** Scroll-follow fires SYNTHETIC mouseovers under a parked cursor. _(src: "Keyboard nav animations — .kb-focused as the sole cursor", 2026-07-06)_
- **Drive markup, nav order and ring targeting from ONE render-order source (`GetRenderGroups` → `GetNavItems` → `GetRenderIndexOf`), with one `(zone, index)` cursor: W/S flow across zones, A/D move within one.** Scroll-follow must reach fully to TOP and BOTTOM at the ends. Tab only leaves text inputs. _(src: "Bag sweep — satchel spine + render-order unification", 2026-07-02)_
- **Reset a sub-panel's cursor on its OPEN EDGE (`if (open && !_wasOpen) idx = 0;` in Tick), not in the opening keystroke.** Mouse opens would leave a stale index. _(src: "Input / keyboard", 2026-05-18)_
- **Don't assume browser `pointer-events`.** A `none` ancestor BLOCKS children set to `auto`, so opt children back in with `all`. Hit-testing uses LAYOUT rects, so transformed UI needs a click-catching backdrop plus a C# hit-test. _(src: "PawPad v7.2–7.4 — mouse router", 2026-07-02)_

## Visual language & style
- **Avoid the "Claude UI signature": uniform 2px rgba borders, 12–16px radii everywhere, layered soft shadows, purple everywhere, low-alpha cards, decorative icons.** Players called it "so Claude generated". Before any border, shadow, glow or radius, ask whether this element needs it. _(src: "Feedback responses", 2026-04-10)_
- **Use glow and halos only as a SIGNAL: on the hero or active element and at signature moments, outside scroll containers.** Never put them on small chrome or as empty-state washes, where a centered icon plus a copy hierarchy works better. Try size, contrast or weight first. _(src: "Feedback responses", 2026-04-10; "Stylistic halo gradients on empty states", 2026-04-16)_
- **Restrain the P5 stamp.** The slab recipe is a 4px radius, a `2px solid rgba(0,0,0,0.55)` border, a hard no-blur offset shadow that steps down by rank, and an 800-weight uppercase label (`OnlineHubPanel .hub-pill`). Use it only on single-instance elements: the shell, title, header pill and one hero CTA. Skew one stamp per surface. Repeated (N≥3) elements get hard accents on the primary instance only. _(src: "Style observations", 2026-04-28; "Concept C — Launcher Hub", 2026-05-03)_
- **Each page wears its PawPad app color as its accent: BEASTS #7B4DDB, SKILLS #FF6BD6, EXPEDITION #EE5421, ONLINE #3F8FE0, BEASTBOOK #2DD4BF, SHOP #FFCE3A (PhoneLauncher Apps registry).** Violet is the one cursor (#7b4ddb fills, #9b6cff rings). Gold is global. Rarity colors match everywhere. Owned vs equipped is split by color, and expiring is amber, not red. _(src: "Beastbook design brief authored for the Claude Design loop", 2026-07-12)_
- **Never transition `border-color` between distant hues.** It passes through mud ("way too many colors"). Pair same-hue borders only, or drop border-color from the transition so the stroke steps while the fill glides. _(src: "One-cursor + feel pass", 2026-07-06)_
- **Never ship an empty detail pane. Default it to the hero pick (daily spotlight, cheapest "NEXT UP", first entry), and render locked entries as pages with earned hints.** Rail controls must adopt the displayed item before acting. _(src: "Sweep — Shop market-stall recomposition", 2026-07-02)_
- **Build collection pages on MonsterRosterPanel: an opaque floating header, a grid of fixed-width cards, and a ~400px sidebar whose pinned identity stack sits above a `flex: 1 1 0; min-height: 0; overflow-y: scroll` body.** Drive the views from one `string detailView` in `BuildHash()`, and reset it on selection. Popup chrome is for transient overlays only. _(src: "MonsterRosterPanel is the canonical layout reference", 2026-04-14)_
- **Style chips from ONE base pill class with color-only variants, a shared explicit `height` (22px) across the row, and a lift-cancelling `:hover` on non-interactive pills.** Otherwise the chips read as "unrelated UI systems colliding". A variant that overrides `transition` must re-list `filter`. _(src: "Unified pill pattern — one `.bb-pill` base", 2026-04-14)_
- **Use iconify/lucide for every icon, glyphs included (★ ◆ ●), keeping official brand images for Discord and Steam.** Map gold→`lucide:coins`, ink→`lucide:feather`, tokens→`lucide:trophy`, diamond rank→`lucide:gem` (no gem currency). Save and profile UI uses game-world marks (flame, paw, element), never user icons. _(src: "Concept C — Launcher Hub", 2026-04-28)_
- **Size primary actions at ~1.4–1.6× the nearest passive surface, with icons around 32px and meaningful labels ≥13px. When chrome shrinks, re-scale its content.** Otherwise actions read as background, and players called the result "too tiny". _(src: "MainMenu editorial-cinematic redesign", 2026-04-23)_
- **Make the VALUE of a label/value pair heavier than the label ("LVL 12", "GOLD 4.2K").** _(src: "UX rule: the DATA in a label/value pair", 2026-04-17)_
- **Mark locked elements with TWO signals, a ~0.4 opacity dim plus a lock or cooldown glyph, and play `SoundManager.PlayDeny()` on hover.** Opacity alone reads as "unselected". _(src: "SkillTreePanel batch polish", 2026-04-17)_
- **Keep the motion budget: one ambient layer per hero, ≤5 infinite loops per screen, subliminal amplitude (1–3px, 2–4s), and a slow ~3s breath (not a flash) for "running" states.** If cutting a layer doesn't flatten the element, cut it. _(src: "Idle-animation budget rule", 2026-04-17)_
- **Keep sound hygiene.** Claims layer click + success + reward. Same-tab re-selects early-return before playing sound. Toggle sounds follow the post-toggle state. Hover sounds play only when a per-family `lastHoveredXId` changes, with no BuildHash writes inside. `onmouseover` re-fires and bubbles, so add `> * { pointer-events: none }`. _(src: "Hover-sound guard pattern for grid cards", 2026-04-14)_
- **[celebrations] Hold a ~600–700ms anticipation beat before the slam, with C#-driven stages and a `pointer-events: none` overlay mounted as a sibling of the modal via `@if`.** Defer the manager commit ~0.4s so roll-ups land at the peak. _(src: "Concept C — Launcher Hub", 2026-06-03)_
- **[tier chains] Mark "you are here" with a stronger border, a type bump and a "CURRENT" chip, and dim the siblings rather than glowing the target.** Color the tier word itself, and fill bars in the current tier's color. _(src: "\"You are here\" recipe", 2026-04-17)_
- **[PawPad] Launcher tiles are literal apps: accent-filled rounded squares with the label below. Route with the angled accent SWIPE (~450ms, ease-out).** It is the one sanctioned full-rainbow surface. _(src: "Phone launcher v2 — app icons + accent swipe", 2026-07-01)_
- **Anchor each hotkey hint next to its control, and reuse key caps at native geometry.** Enlarging a cap broke its centering three times. _(src: "Style observations", 2026-05-18)_

## Workflow & verification
- **Grep the repo for working usage before trusting any engine claim, and treat the runtime console as ground truth.** Property support can be read from `Sandbox.UI.BaseStyles` via `System.Reflection.Metadata`, because the .NET 10 DLLs don't load. A persistent parse error means grep all of `Code/UI/`, since every bundled scss parses, mounted or not. _(src: "Feedback responses", 2026-04-17; "Concept C — Launcher Hub", 2026-06-08)_
- **Compile success is SILENCE.** Match failure timestamps to your save, look for `HotloadObjectIndex took Nms`, and attribute errors in shared trees via `git status`. If new markup runs an old method body after a stalled DoSwap, force another compile. _(src: "PawPad v6/v7 — animated icons", 2026-07-02)_
- **Drive the sbox MCP by hand if native tools are missing: POST JSON-RPC `tools/call` to `http://127.0.0.1:7269/mcp` (stateless) with `compile_status`/`read_console`/`console_command`/`camera_screenshot`, and decode the base64 PNG.** Shots take ~2.5s, so verify settled end states and use freeze commands. See Unresolved on UI capture. _(src: "Specimen Hall — Beastbook identity build", 2026-07-12)_
- **Build temporary `dev_<panel>` ConCmds that route via `NavManager.GoTo` plus state args and clear covering overlays (`PhoneLauncher.Close()`).** From the main menu, call one TWICE. The command existing proves the hotload landed. _(src: "Skill Tree gold redesign + MCP-driven verification loop", 2026-07-12)_
