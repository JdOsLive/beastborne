#### Cross-cutting notes (Meta/reward & Main menu)
- **A second, uncomponentized design system.** The "dock-tier popup" (`#14151b` r26 slab, `#1a1c23` tiles, `#23252e` glyph squares, skew kicker, `.close-btn`) is copy-pasted into 11 scss files, and 7 of the 8 screens here use it instead of the dossier tokens and shared primitives (0 Bb* usages across the family). Phase 1 needs a **`BbModalShell`**: a centered-modal variant of the page shell with an app-color kicker, Q close cap, mount-keyed entrance, UIModalState registration and a keyboard-graph hook built in. Most of this family then becomes a content swap.
- **Meta screens have no app color, so they default to violet.** Gift, Credits, Tutorial (kicker plus Next button), Achievement and the menu's Patch Notes all use `#9b6cff` as the page accent, which contradicts "violet = the one cursor". - **Input parity is the biggest gap.** Trading and Gift have **zero** keyboard support (Trading also blocks GameHUD keys while open). Achievement and Daily are close-only. GiftInbox isn't in UIModalState, so Space fires PLAY behind it. The Phase 1 input model must make small-modal graphs (tabs + list + CTA) nearly free, and one shared `.kb-key` must replace the three local cap styles.
