Build notes · costs · the arithmetic

Razor (PhoneLauncher.razor:621-643, ActiveEffectsPanel.razor:341-373 · about 12 lines). GetPhoneBoosts stops upper-casing labels (2 sites — Title Case comes free from ItemDefinition.Name / GetBoostLabel) and strips the " for N waves / attempts" suffix from GetEffectDescription for the phone line (one helper: cut at " for "); shop-boost rows send "+50% gold"-style text as Source instead of "shop boost"; the value span becomes the chip (class .pl-fx-chip, .last when RemainingText is 1 use or Remaining under 60 s); the tick parity classes move from the numeral to the chip.

SCSS (about 60 lines net, mostly value swaps). .pl-fx-row 56→60, bg #1c1830, hover #262040, kb #282246; .pl-fx-content 57; .pl-tile 40 / .pl-tile-img 32 (effects + skill rows; alerts untouched this pass); .pl-fx-name 15/800 cream no transform; .pl-fx-src → TextDim 12/700; NEW .pl-fx-chip (22 r11 pad 0 10 #131019 / #a79dbe, .last yellow two-tone); .pl-fx-strip track #15121f, 508 (row minus seam); plFxOut heights 60; plValTick → plChipTick bg + ink twins. DELETE: .pl-fx-val + .last-min + .pl-pulse-*, plLastMinA/B, .pl-fx-fill.amber, the brown tone trio, .pl-tile-glyph.fx yellow.

Art (flagged, not blocking). Consumable PNGs are 51×51 (arcane_draught, iron_skin_oil, contract_incense, hunters_focus…): no integer scale into a 32 slot. Re-export at 64 like the boosts folder; until then the resample is no worse than today's 24px render of the same 51px source.

No server work, no new data source. Every string drawn here exists in GetPhoneBoosts / GetPhoneSkills today (the skill effect line is the one soft spot — see the anatomy note; the row reads fine without it).

Cut at least as much as you add: CUT 6 — the brown tone ladder (4 tones) · the duplicated duration in the effect line · the italic yellow value voice · the amber hue · the 1 Hz pulse · the "shop boost" line. ADD 2 — the count chip (which REPLACES the value, so the row's element count is unchanged: tile · name · effect · chip · strip) · 6 px of tile. Voices per row 4 → 2.
