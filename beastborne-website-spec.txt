# Beastborne Website - Design & Content Specification

## Overview

Beastborne is a roguelike creature-collection game built in s&box where players (called **Tamers**) capture, train, breed, and battle fantastical creatures called **Beasts**. The website serves as a companion hub for players to check game stats, browse the bestiary, view player profiles, and support the game through donations.

**Current Game Version:** v0.8.0

### Aesthetic
- **Dark mode** with deep navy/purple tones
- **Glass morphism** — translucent panels with subtle white borders
- **Glowing purple accents** on interactive elements
- **Gradient overlays** for depth (purple and gold)
- **Rounded corners** (8-12px)
- **Multi-layer shadows** for 3D depth
- **Vignette/cinematic** feel with darkened edges

### Font
- **Exo2** (Bold, SemiBold, ExtraBold, Black weights available)
- Clean, modern sci-fi feel
- Google Fonts alternative: "Exo 2" is available on Google Fonts

### Button Styles

| Type | Background | Hover | Use Case |

### 4. Game Stats / Info Page

A public-facing page with game data and system explanations.

**Sections:**

#### Elements & Type Chart
- Visual grid showing all 11 elements
- Type effectiveness chart (strengths & weaknesses)
- Each element with its icon and color

#### Battle System
- Move-based combat (6 stats: HP, ATK, DEF, SpA, SpD, SPD)
- Turn order based on Speed
- Type effectiveness multipliers
- Status effects & field effects
- Team-based (up to 6 monsters per team)

#### Expedition System
- PvE zones with themed elements
- Wave-based progression (5+ waves per expedition)
- Boss encounters on final waves
- Hard Mode (unlocked via skill tree, +50% rewards)
- Auto-farming / background battle mode

#### Contract System
- Monsters are caught via "contracts" using Contract Ink
- Negotiation strategies: Generous, Fair, Strict, Gold-focused
- Caught monsters have personality-driven demands:
  - **Bloodthirsty** — Wants battles
  - **Greedy** — Wants gold tributes
  - **Ambitious** — Wants to level up
  - **Social** — Wants companions
  - **Lazy** — Wants rest
  - **Competitive** — Wants arena victories
- Satisfaction system (0-100): Devotional > Content > Neutral > Unhappy > Rebellious

#### Evolution & Breeding
- Multi-stage evolution lines (base -> mid -> final)
- Evolution triggered by level + move learned
- Breeding passes genetic traits to offspring
- Genetics affect stat growth & move pools

#### Arena / PvP
- Ranked ladder: Unranked -> Bronze -> Silver -> Gold -> Platinum (5 tiers each)
- Seasonal resets
- Placement matches
- Win streaks tracked

#### Items & Relics

**Consumables (single-use):**

| Iron Skin Oil | DEF +25 for 3 turns |

## Technical Notes

### Responsive Design
- Mobile-first approach
- Bestiary grid should collapse from 4 columns -> 2 -> 1
- Stats bars should be touch-friendly on mobile

### Animations
- Subtle hover effects on cards (lift + glow, matching the game)
- Smooth page transitions
- Particle/nebula background effect on hero section (optional)
- Monster sprites can use idle animation frames if available

### Data
- Monster data can be hardcoded initially (143 species is manageable)
- Player lookup would need an API endpoint from the game server (future feature — can be a placeholder initially)
- Consider JSON data files for easy updates

### SEO
- Each monster should have its own URL-friendly page (`/bestiary/embrik`)
- Meta descriptions with monster lore
- Open Graph tags for social sharing (monster images)
